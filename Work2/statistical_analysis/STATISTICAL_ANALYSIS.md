# Statistical Analysis — Work 2

Statistical analysis of kNN, SVM, and Random Forest on the Soybean and Hypothyroid datasets.

The scripts use corrected paired t-tests for 10-fold cross-validation and Holm adjustment for multiple comparisons.

## 1. knn_statistical_analysis.py

Compares the top 5 kNN configurations based on mean accuracy.

**Inputs:**
- `../knn_experiments/soybean_fold_results.csv`
- `../knn_experiments/hypothyroid_fold_results.csv`

**Outputs:**
- `../results/soybean_knn_statistical.csv`
- `../results/hypothyroid_knn_statistical.csv`

## 2. svm_rf_statistical_analysis.py

Compares the top 5 hyperparameter configurations separately for SVM and Random Forest.

**Inputs:**
- `../results/svm_grid_results.csv`
- `../results/rf_grid_results.csv`

**Outputs:**
- `../results/soybean_svm_statistical.csv`
- `../results/hypothyroid_svm_statistical.csv`
- `../results/soybean_rf_statistical.csv`
- `../results/hypothyroid_rf_statistical.csv`

## 3. algorithm_statistical_analysis.py

Compares the best configurations of kNN, SVM, and Random Forest using paired fold accuracies.

**Inputs:**
- `../knn_experiments/soybean_fold_results.csv`
- `../knn_experiments/hypothyroid_fold_results.csv`
- `../results/svm_grid_results.csv`
- `../results/rf_grid_results.csv`

**Outputs:**
- `../results/soybean_algorithm_statistical.csv`
- `../results/hypothyroid_algorithm_statistical.csv`

## 4. prepare_final_results.py

Combines statistical results, parameter results, and figures for the final report.

**Outputs:**
- `../final_report_results/all_statistical_results.csv`
- `../final_report_results/all_parameter_results.csv`
- `../final_report_results/best_models_summary.csv`
- `../final_report_results/figures/` — accuracy comparison and parameter plots

## Installation

Install the required Python libraries:

```bash
python -m pip install numpy pandas scipy matplotlib scikit-learn
```

## How to Run

Run the following commands from the repository root after generating the experiment CSV files:

```bash
python Work2/statistical_analysis/knn_statistical_analysis.py
python Work2/statistical_analysis/svm_rf_statistical_analysis.py
python Work2/statistical_analysis/algorithm_statistical_analysis.py
python Work2/statistical_analysis/prepare_final_results.py
```

Run the scripts in this order because `prepare_final_results.py` uses the results generated by the previous scripts.

## Notes

- Statistical comparisons are exploratory because model selection and testing use the same folds.
- Hypothyroid kNN results require verification.
- Keep the original experiment CSV files and figures because the analysis scripts depend on them.
